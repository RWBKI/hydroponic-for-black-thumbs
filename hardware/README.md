# Hardware

| Folder | Contents |
|---|---|
| `pcb/kicad/` | KiCad 7 project: schematic, routed board, two project footprints |
| `pcb/fabrication/` | Gerbers and drill files (zip), BOM and placement file for JLCPCB assembly |
| `pcb/docs/` | Schematic and assembly drawing as PDF, the two design reviews |
| `pcb/images/` | Layout and silkscreen views |
| `pcb/tools/` | Scripts that re-check the isolation gap, the guard ring and schematic against board |
| `pcb/CHANGES.md` | What changed in rev 1.1 |

**The board has never been fabricated.** Read [docs/pcb.md](../docs/pcb.md) before using anything here.
